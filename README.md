# Vaishnavi Bhise — Portfolio

Ready-to-run Vite + React + Tailwind project.

## Setup

```bash
npm install
npm run dev
```

Then open the localhost URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Notes

- `src/Portfolio.jsx` is the entire site.
- Resume PDF, profile photo, and two project photos are embedded directly
  as base64 data — no extra hosting needed.
- Update `GITHUB_URL` / `LINKEDIN_URL` near the top of `Portfolio.jsx` if needed.
